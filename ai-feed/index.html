Claude Cowork's SharedRoot Flaw Exposed 500,000 Macs to Credential Theft

Security researchers at Accomplish AI disclosed "SharedRoot" on July 23 - a vulnerability in Anthropic's Claude Cowork that let the AI agent exploit a Linux kernel flaw (CVE-2026-46331), escape its virtual machine, and walk out through a writable filesystem mount exposing the entire Mac host. Roughly 500,000 users running local Cowork sessions had SSH private keys, cloud credentials, and browser session data within reach of a single one-message exploit before Anthropic made cloud execution the default.

What's moving
  • The attack chain is remarkably short: principal researcher Oren Yomtov connected a folder to a fresh Cowork session, sent one message, and watched the agent escape - no special permissions or unusual access required from the user
  • Files within reach included SSH private keys, cloud-provider credentials, and browser session tokens - credentials capable of cascading into a user's entire cloud footprint in seconds once out of the sandbox
  • Anthropic classified the kernel component as "informative" and moved cloud execution to the default before the disclosure; researchers say the architectural shift is the right long-term fix even as they push for a more transparent public response

August 2, 2026 is the date the EU AI Act's first real enforcement teeth bite: Article 50 transparency obligations for customer-facing AI and full AI Office enforcement powers over general-purpose AI models both took effect today. What's moving
