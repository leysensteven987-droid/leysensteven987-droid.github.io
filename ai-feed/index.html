OpenAI Presence Launches - Voice and Chat Agents Resolve 75% of Enterprise Support Calls Without a Human in the Loop

Launched July 22, OpenAI Presence is an enterprise platform for deploying task-scoped AI agents across customer support, outbound sales, and internal IT workflows using GPT-5.6. OpenAI's own English-language phone support runs on Presence and resolves three-quarters of inbound issues autonomously. BBVA Mexico, SoftBank Japan, and Retail Insurance Australia are live production customers, with rollouts supported by Forward Deployed Engineers through a limited general availability program.

What's moving
  • Unlike general-purpose chatbot integrations, each Presence deployment is policy-scoped: enterprises set what the agent can do, when it requires approval, and when to escalate - the governance layer that previous API-based agent deployments left to customers to build themselves, and the missing piece that has held enterprise deployments to pilots
  • Presence uses Codex to propose production updates based on live escalation data, creating a self-improving feedback loop where the agent learns from its own failures without requiring human prompt engineers to manually iterate between deployments
  • SoftBank's Japanese-language rollout marks Presence's first non-English production deployment - a significant test of whether GPT-5.6's enterprise-grade accuracy holds across morphologically complex languages where benchmark scores are less well-characterized than in English

FLUX 3 Arrives: Black Forest Labs Ships the First Model That Generates Video, Audio, Images, and Robot Actions From One Set of Weights

Announced July 23, FLUX 3 is the first frontier model to unify image generation, text-to-video up to 20 seconds, native in-sync audio, and robotic action prediction in a single architecture trained across all modalities simultaneously. The video variant is in early access now at bfl.ai; image, action, and open-weight Dev releases follow in coming weeks. Black Forest Labs' Self-Flow architecture eliminates the separate decoders that prior multimodal models bolt onto shared embeddings, letting the model learn cross-modal structure rather than stitching outputs together after the fact.

What's moving
  • Native audio generation is the key differentiator: FLUX 3 produces video and in-sync audio as one generation pass, eliminating the alignment artifacts that plague models with separate audio tracks stitched after rendering - and making it the first public model where the sound and motion are causally linked from the same latent
  • FLUX 3 Action extends the same weights into physical AI: a model that generates a video clip can also predict robot motion trajectories, bridging creative generation and embodied AI in a single release and opening new paths for training data synthesis for robotics
  • A planned open-weight FLUX 3 Dev release will put a genuine frontier multimodal architecture within reach of independent researchers - following the FLUX 1 and FLUX 2 playbook, which made Black Forest Labs the de facto provider of base models for image generation fine-tuning

  • Anthropic's red-team capability disclosure (red.anthropic.com/2026/mythos-preview/) functions as a public reference document: by publishing what Mythos 5 can and cannot do on adversarial security tasks, Anthropic gives partner vetting committees and regulators a standard against which to assess access risk - a new kind of AI transparency that goes beyond benchmark tables
